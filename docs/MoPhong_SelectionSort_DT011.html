3. Đối đầu trực quan: Lựa chọn vs Đổi chỗ

Cùng chạy trên một dãy, từng bước song song — xem số lần đổi chỗ tách xa nhau dù số so sánh bằng nhau.

Lựa chọn (selection)

0 đổi · 0 so sánh

Đổi chỗ (exchange)

0 đổi · 0 so sánh

Giả mã (đang chạy tô sáng)

Độ phức tạp: n(n−1)/2 so sánh

Thời gian O(n²) — số so sánh không đổi với mọi dữ liệu vào; số đổi chỗ ≤ n−1.
